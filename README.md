# 🏢 에이전트 사무실 (AgentOffice)

Claude Code가 PC에 남기는 세션 파일을 **대본**으로 삼아, 2층짜리 아이소메트릭 건물의 캐릭터들이 그걸 **연기**하는 뷰어입니다.

- **2층 사무실**: 사장(나)이 업무를 지시하면 Claude가 사장실로 와서 업무를 받아 가고, 자료실·개발실·서버실을 오가며 일합니다.
  서브에이전트는 엘리베이터로 출근해 Claude에게 업무를 배정받고, 일을 마치면 보고하고 퇴근합니다.
- **1층 작업실**: 백그라운드에서 돌아가는 일이 모입니다. 백그라운드 셸 작업은 작업봇이 기계를 돌리며 출력 마지막 줄을 보여 주고,
  백그라운드 서브에이전트는 1층으로 출근해 작업 지시판을 확인하고 일합니다.

> **토큰은 하나도 안 씁니다.** AI를 부르지 않고 세션 파일만 읽습니다.

## 빠르게 시작하기

Node 18 이상이면 됩니다. 웹 버전은 의존성이 없습니다.

```bash
npm start        # → http://localhost:4777
```

Claude Code에서 아무 작업이나 시작하면 캐릭터가 움직입니다.

Claude 없이 미리 보고 싶으면 데모를 실행하세요. 가짜 세션을 한 줄씩 써서 사무실을 움직입니다.

```bash
npm run demo     # → http://localhost:4778
```

## 데스크톱 앱 (Windows)

### 설치

`dist/AgentOffice-Setup-1.1.0.exe`를 실행합니다. 설치 없이 쓰려면 `dist/AgentOffice-Portable-1.1.0.exe`를 실행하세요.

서명하지 않은 exe라서 처음 실행할 때 SmartScreen 경고가 뜰 수 있습니다. **추가 정보 → 실행**을 누르면 됩니다.

### 기능

| 기능 | 설명 |
|---|---|
| 창 | 앱 안에서 서버가 같이 뜨고 사무실 화면을 엽니다 (포트 47770, 사용 중이면 빈 포트) |
| 트레이 | 창을 닫아도 트레이에 남아 계속 지켜봅니다. 🟢 = Claude 작업 중, 🟡 = 나한테 질문 중. 마우스를 올리면 프로젝트별 상태가 보입니다 |
| 알림 | 아래 표 참고 |
| 미니 모드 | 560×380 작은 창이 화면 오른쪽 아래에 항상 위로 떠 있습니다 (사무실만 표시) |
| 자동 실행 | Windows 로그인 시 트레이로 조용히 시작합니다 |

트레이 아이콘을 우클릭하면 메뉴가 나옵니다: 열기, 미니 모드, 알림 설정과 **알림 테스트 보내기**, Windows 시작 시 자동 실행, 브라우저에서 열기, 종료.

### 알림

앱은 창에 띄운 세션과 상관없이 **최근 10분 안에 움직인 모든 세션**을 지켜봅니다.
그래서 어느 프로젝트에서 Claude를 쓰든 알림이 옵니다. 알림 제목 앞에는 `[프로젝트명]`이 붙습니다.

| 알림 | 언제 |
|---|---|
| ❓ Claude가 질문이 있어요 | Claude가 나한테 질문할 때 (`AskUserQuestion`) |
| ✅ Claude가 답을 마쳤어요 | 10초 넘게 일한 뒤 답을 마쳤을 때 |
| 👋 서브에이전트 일 끝남 | 서브에이전트가 결과를 돌려줬을 때 |
| ✅ / ❌ 백그라운드 작업 완료·실패 | 1층의 백그라운드 셸 작업이나 백그라운드 서브에이전트가 끝났을 때 |

지금 창으로 보고 있는 세션의 사건은 알리지 않습니다.

### 직접 빌드하기

```bash
npm install
node node_modules/electron/install.js   # npm 11은 Electron 실행 파일을 자동으로 받지 않음 (아래 문제 해결 참고)
npm run app                             # 개발용으로 바로 실행
npm run dist:win                        # dist/ 에 설치 파일과 포터블 exe 생성
npm run icons                           # 아이콘 PNG·ICO 다시 만들기
```

mac용은 `npm run dist:mac`입니다. 이 명령은 Mac에서 실행해야 합니다.

## 어떻게 동작하나

Claude Code는 모든 대화를 PC에 파일로 남깁니다 ([공식 문서](https://code.claude.com/docs/ko/sessions#export-and-locate-session-data)).

```
~/.claude/projects/<프로젝트>/<세션ID>.jsonl                          ← 메인 대화
~/.claude/projects/<프로젝트>/<세션ID>/subagents/agent-xxxx.jsonl     ← 서브에이전트 대화
~/.claude/projects/<프로젝트>/<세션ID>/subagents/agent-xxxx.meta.json ← 서브에이전트 종류·설명
```

파일의 **한 줄이 사건 하나**입니다. 내가 친 말, Claude의 생각, 도구 호출, 도구 결과가 한 줄씩 붙습니다.

1. **`server.js`**가 0.25초마다 파일 끝에 새 줄이 붙었는지 확인합니다.
2. 새 줄이 오면 **`lib/classify.js`**가 "그럼 캐릭터는 뭘 해야 하지?"로 바꿉니다. 예: `Read app.js` → "자료실로 가서 *app.js 읽는 중* 말풍선".
3. SSE로 브라우저에 보내면 **`public/js/`**의 캐릭터가 걸어가고 말합니다.

처음 접속하면 최근 기록을 다시 읽어서 지금 상태부터 보여 줍니다.

## 화면 구성

| 영역 | 내용 |
|---|---|
| **프로젝트** (왼쪽) | 최근에 바쁜 프로젝트가 위로 오고, 활동 중이면 초록 점이 켜집니다. 프로젝트를 누르면 그 프로젝트의 최근 세션을 자동으로 따라가고, 세션을 누르면 그 세션에 고정됩니다 |
| **건물** (가운데) | 위쪽 탭(`2F 사무실` · `1F 작업실`)이나 오른쪽 아래 미니 단면도로 층을 바꿉니다. 안 보는 층도 계속 돌아가고, 바쁜 층은 단면도 창문에 불이 켜집니다. 드래그로 이동, 휠로 확대, 더블클릭으로 원위치 |
| **사무실 사람들** (오른쪽) | 두 층의 모든 사람과 작업봇. 층 표시(2F·1F), 상태(업무 받는 중·고민 중·작업 중·질문 중·보고 중·퇴근 중), 지금 하는 일. 누르면 그 층으로 가서 카메라가 그 사람을 비춥니다 |
| **활동 로그** (오른쪽) | 세션 파일 한 줄 = 사건 하나 |

무대 위쪽의 `◀ 프로젝트`, `사람들 · 로그 ▶` 버튼으로 양쪽 패널을 접고 펼 수 있습니다.
창이 900px보다 좁으면 왼쪽 프로젝트 목록이 기본으로 접힙니다.

### 층별 구성

| 층 | 구역 | 하는 일 |
|---|---|---|
| **2F 사무실** | 사장실 | 내 자리. 업무 지시를 받으러, 질문하러, 보고하러 Claude가 찾아옵니다 |
| | Claude 자리 | Claude가 쉬며 생각하는 곳 |
| | 자료실 · 개발실 · 서버실 · 정보검색실 · 회의실 | 도구에 따라 오가는 작업장 |
| | 카페 · 엘리베이터 | 서브에이전트 출퇴근 |
| **1F 작업실** | 충전소 | 작업봇이 쉬는 충전 패드 |
| | 기계실 | 백그라운드 셸 작업이 돌아가는 기계. 상태등: 파랑 = 실행 중, 초록 = 완료, 빨강 = 실패(연기) |
| | 작업 지시실 | 벽의 작업 지시판에 돌고 있는 작업 목록. 백그라운드 서브에이전트가 출근하면 여기서 지시를 확인 |
| | 작업대 · 통신실 | 백그라운드 서브에이전트가 파일 작업·웹 검색을 하는 곳 |

### 업무 흐름

1. **사장(나) → Claude**: 프롬프트를 치면 내 캐릭터가 지시하고, Claude가 사장실로 와서 "📋 네, 사장님! 업무 접수했습니다" 하고 업무를 받아 갑니다.
2. **Claude → 서브에이전트**: 서브에이전트가 엘리베이터로 출근해 Claude 옆으로 와서 업무를 배정받은 뒤 작업장으로 갑니다.
3. **백그라운드 작업 → 1층**: `run_in_background`로 실행한 명령은 1층 작업봇이 충전소에서 깨어나 기계를 돌립니다. 끝나면 ✅/❌를 띄우고 충전소로 돌아갑니다.
4. **보고**: 서브에이전트는 결과를 Claude에게(백그라운드면 작업 지시판 앞에서) 보고하고 퇴근합니다.

### 등장인물

| 캐릭터 | 모습 |
|---|---|
| 나 (사장) | 정장 + 빨간 넥타이, 머리 위 👑. 이름표는 PC 사용자명 |
| Claude | 주황 옷, 머리 위에 반짝이. 생각하거나 일할 때 반짝이가 빨리 돕니다 |
| 작업봇 | 바퀴 달린 회색 로봇. 일하면 불꽃이 튀고, 실패하면 눈이 ✗ |
| 탐색 (`Explore`) | 초록 옷 + 탐험모자 |
| 계획 (`Plan`) | 파란 옷 + 안경·넥타이 |
| 범용 (`general-purpose`) | 보라 옷 + 노란 모자 |
| 직접 만든 서브에이전트 | 이름에 따라 정해지는 색 + 하얀 머리띠 |

## 말풍선과 방 배정

### 말풍선

| 기록 | 연기 |
|---|---|
| 💬 Claude 답변 | 말풍선 대사 |
| 💭 생각 기록 | 구름 말풍선 + "12s째 고민 중" |
| 📖 도구 호출 | "app.js 읽는 중 · 3s" (끝나면 ✓) |
| ❌ 도구 실패 | 빨간 말풍선 + 식은땀 |
| 👤 내 프롬프트 | 내 캐릭터가 타자 치며 말함 |
| ❓ 나한테 질문 | Claude가 사장실로 와서 노란 말풍선 |
| 🚀 백그라운드 실행 | Claude가 서버실에서 실행하고, 1층 작업봇이 기계를 돌림 |
| ✋ Esc로 중단 | 내 캐릭터가 "잠깐, 멈춰!", Claude가 "😳 넵, 멈출게요!" |

### 방 배정

| 도구 | 방 |
|---|---|
| Read · Grep · Glob · Skill | 📚 자료실 |
| Edit · Write · NotebookEdit | 💻 개발실 |
| Bash · PowerShell | 🗄️ 서버실 (명령 내용에 따라 다른 방) |
| WebSearch · WebFetch · MCP 도구 | 🌐 정보검색실 |
| TodoWrite · 계획 · 서브에이전트 위임 | 📋 회의실 |
| AskUserQuestion | 👑 사장실 |

같은 Bash라도 명령을 까 보고 방을 나눕니다.

| 명령 | 방 |
|---|---|
| `rg` · `grep` · `cat` · `ls` · `git diff` · `git log` | 📚 자료실 |
| `sed -i` · `>` 리디렉션 · `mv` · `rm` · `mkdir` | 💻 개발실 |
| `curl` · `wget` · `gh` | 🌐 정보검색실 |
| 그 밖 (`npm` · `node` · `git commit` …) | 🗄️ 서버실 |

## 서브에이전트

### 사무실에서 보이는 모습

1. 세션 폴더 안 `subagents/`에 `agent-xxxx.jsonl`이 새로 생기면 엘리베이터 문이 열리고 출근합니다.
2. 같이 생기는 `agent-xxxx.meta.json`에서 종류(`agentType`)와 맡은 일(`description`)을 읽습니다. 종류에 맞는 옷을 입고, 이름표에 `종류 · 맡은 일`을 붙입니다.
3. 그 파일도 똑같이 따라 읽으며 방을 오갑니다.
4. 마지막 답변이 기록되면 Claude 옆으로 가서 결과를 말하고 "👋 퇴근합니다!" 한 뒤 엘리베이터로 나갑니다.

### 기본 제공 서브에이전트 (설정 없음)

Claude Code에는 처음부터 들어 있는 서브에이전트가 있습니다.

| 종류 | 하는 일 |
|---|---|
| `Explore` | 코드 찾기·훑어보기 (읽기만 함) |
| `Plan` | 구현 계획 세우기 |
| `general-purpose` | 여러 단계 작업 전반 |

일이 크면 Claude가 알아서 맡기기도 하지만, 직접 시키는 게 확실합니다.

```
Explore 서브에이전트로 이 프로젝트의 인증 흐름을 조사해줘
서브에이전트 두 개로 프론트엔드와 백엔드를 나눠서 동시에 살펴봐줘
```

### 직접 만들기

마크다운 파일 하나가 서브에이전트 하나입니다.

| 위치 | 범위 |
|---|---|
| `<프로젝트>/.claude/agents/이름.md` | 이 프로젝트에서만 |
| `~/.claude/agents/이름.md` | 모든 프로젝트에서 |

예: `.claude/agents/code-reviewer.md`

```markdown
---
name: code-reviewer
description: 코드 변경 후 버그·보안 문제를 검토할 때 사용. 수정이 끝나면 적극적으로 사용할 것.
tools: Read, Grep, Glob, Bash
model: sonnet
---
당신은 꼼꼼한 코드 리뷰어입니다.
변경된 파일을 읽고 버그, 보안 문제, 놓친 예외 처리를 찾아
심각한 것부터 파일:줄 번호와 함께 보고하세요. 코드는 직접 고치지 마세요.
```

| 항목 | 역할 |
|---|---|
| `name` | 부를 때 쓰는 이름. 사무실에서는 이 이름이 종류로 표시됩니다 |
| `description` | Claude가 언제 맡길지 판단하는 기준. "언제 쓰는지"를 구체적으로 써야 알아서 잘 맡깁니다 |
| `tools` | 쓸 수 있는 도구. 빼면 전부 사용 가능. 읽기만 할 거라면 Edit·Write를 빼세요 |
| `model` | 생략하면 기본 모델. 가벼운 일은 `haiku`로 비용을 아낄 수 있습니다 |
| 본문 | 서브에이전트에게 주는 지시문 |

터미널에서 `claude`를 실행한 뒤 `/agents`를 쓰면 메뉴로 만들고 고칠 수도 있습니다.

직접 만든 서브에이전트에 전용 복장과 한글 이름을 주려면
`public/js/actors.js`의 `TYPE_KO`(한글 이름)와 `styleFor()`(옷·소품)에 항목을 추가하세요.

## 설정

| 항목 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `4777` | 웹 버전 포트 (앱은 47770) |
| `CLAUDE_PROJECTS` | `~/.claude/projects` | 세션 파일을 읽을 폴더 |

앱 설정은 `%APPDATA%\AgentOffice\settings.json`에 저장됩니다 (알림 켜기·끄기, 미니 모드, 창 위치).

## 프로젝트 구조

```
server.js            세션 파일 따라 읽기, SSE, 프로젝트 목록 API, 백그라운드 작업 출력 읽기, 알림용 전체 세션 감시
lib/classify.js      jsonl 한 줄 → 캐릭터 이벤트 (방 배정, 말풍선 문구)
```

## 문제 해결

**알림이 안 떠요**
1. 트레이 메뉴 → 알림 → **알림 테스트 보내기**로 확인합니다.
2. 테스트 알림도 안 뜨면 Windows 설정 → 시스템 → 알림에서 **AgentOffice**가 켜져 있는지, 방해 금지 모드가 켜져 있지 않은지 확인합니다.
3. `%APPDATA%\AgentOffice\agentoffice.log`에 알림 기록과 실패 사유가 남습니다.
4. "답을 마쳤어요" 알림은 10초 넘게 걸린 작업에만 뜹니다. 지금 창으로 보고 있는 세션은 알리지 않습니다.

**`npm run app`이 Electron을 못 찾아요**
npm 11은 패키지 설치 스크립트를 기본으로 막기 때문에 Electron 실행 파일이 받아지지 않습니다. 한 번만 실행하세요.

```bash
node node_modules/electron/install.js
```

**SmartScreen 경고가 떠요**
서명하지 않은 exe라서 그렇습니다. **추가 정보 → 실행**을 누르세요.

**"도구 N회"가 실제보다 적어요**
접속할 때 다시 읽은 최근 사건(120개) 범위에서만 셉니다.

**캐릭터가 안 움직여요**
- 상단 `LIVE` 표시가 초록인지 확인하세요.
- 왼쪽 프로젝트 목록에서 지금 Claude를 쓰는 프로젝트가 선택돼 있는지 확인하세요.
- 백그라운드 작업은 1층에 있습니다. 위쪽 `1F 작업실` 탭을 눌러 보세요.
